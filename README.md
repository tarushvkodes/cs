## Overview

**Tarushv's CS Resources** is designed to be a one-stop destination for anyone looking to deepen their understanding of computer science. The website is divided into several sections:

- **Online Courses:** Links to top platforms like Coursera, edX, Udacity, MIT OpenCourseWare, Khan Academy, Pluralsight, FutureLearn, and Udemy.
- **Interactive Tutorials:** Features interactive coding tutorials from freeCodeCamp, Codecademy, W3Schools, and GeeksforGeeks.
- **Books & Documentation:** Includes resources such as MDN Web Docs, Stack Overflow, classic textbooks (e.g., CLRS, Clean Code), and Tutorialspoint.
- **Coding Practice:** Curates coding challenge sites like LeetCode, HackerRank, Project Euler, and Codewars.
- **Competitive Programming:** Lists platforms for competitive programming including USACO, Codeforces, TopCoder, AtCoder, SPOJ, CSES, Kattis, Google Kick Start, CodeChef, Clash of Code, Timus Online Judge, and CodeAbbey.
- **Tools & Communities:** Offers links to collaboration and community platforms like GitHub, Stack Exchange, Reddit (r/learnprogramming), and Dev.to.
- **Specialized & Research:** Provides direct access to specialized resources like Kaggle, Papers with Code, arXiv, and ResearchGate.

## Features

- **Responsive Design:** Uses a responsive layout that adapts to various screen sizes.
- **Smooth Animations:** Integrated with the AOS (Animate On Scroll) library to animate elements as you scroll.
- **Sticky Navigation:** A header with anchor links enables quick jumps between sections.
- **Resource Cards:** Each resource is showcased in a card layout with a brief description and a button that opens the external site in a new tab.
- **Performance Focused:** Built as a static website ensuring fast loading times with minimal external dependencies.

## Technologies

- **HTML5:** Structure and content.
- **CSS3:** Styling and layout.
- **JavaScript:** For initializing animations and interactive elements.
- **AOS (Animate On Scroll):** For scroll-triggered animations.
- **Google Tag Manager:** For analytics and tracking.
- **GitHub Pages:** Used to host the website.

## Installation

To run this website locally:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/tarushvkodes/cs.git

	2.	Navigate to the Project Directory:

cd cs


	3.	Open the index.html File:
Open index.html in your preferred web browser. Alternatively, you can use a local server (for example, the Live Server extension for VS Code) for easier development.

	Note: Ensure that the background image file (banner.png) is in the correct relative path.

Usage
	•	Navigation: Use the sticky header links (Courses, Tutorials, Books & Docs, Practice, Competitive, Tools & Communities, Others) to jump between sections.
	•	Resource Cards: Click the “Visit” button on each card to open the external resource in a new tab.
	•	Animations: Enjoy the scroll-based animations powered by AOS, which enhance the visual experience without compromising performance.
